# UI Audit 001

Scope: current inventory dashboard UI.

## Findings

### 1. HIGH: Dashboard values appear real but have no data source

`src/pages/dashboard/dashboard.jsx` renders fixed inventory totals and a fixed seven-day chart. The request and low-stock views use empty arrays in `src/components/dashboard/requestTable.jsx` and `src/components/dashboard/lowStock.jsx`, so the dashboard presents numeric data without showing where it came from or marking it as placeholder content. This conflicts with R-17 and R-38.

### 2. HIGH: Data views have no empty, loading, or error states

The request and low-stock lists render only mapped rows. With their current empty arrays, those sections are blank below the headers, and neither view communicates whether data is empty, loading, or unavailable. R-27 requires these states for data views.

### 3. MEDIUM: Several visible controls do not perform an action

The dashboard date button, "Lihat Semua" buttons, and request "Detail" buttons have no handlers or navigation. The chart period selector also does not update the fixed chart. These controls appear interactive but do not carry out their labeled action, contrary to R-26.
